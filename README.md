# 🎓 Student Attendance Dashboard

An interactive Power BI dashboard analyzing student registration and attendance performance from January to May 2026, built to help stakeholders monitor enrollment and attendance trends at a district level.

## 🎯 Objective
To transform raw student registration and attendance data into an interactive, decision-ready dashboard that helps stakeholders monitor registration, attendance, and district-level performance efficiently.

## 🔍 Key Insights & KPIs
- Total Students & Registered Students
- Total Attendance & Unique Students Attended
- Attendance Rate (%)
- Registration vs Attendance Trend
- District-wise Enrollment vs Registration
- District-wise Attendance Performance
- Unique Attendance % by District
- Interactive Month & District filters

## 🛠️ Tools & Technologies
| Category | Tools |
|---|---|
| Data Source | Excel (exported as CSV) |
| Visualization & Modeling | Power BI, DAX |
| Data Transformation | Power Query |
| Data Prep | Data Cleaning, Data Modeling |

## 🧠 Approach
1. **Data Cleaning & Modeling** — Exported registration/attendance records from Excel as CSV, imported into Power BI, and cleaned/structured them using Power Query.
2. **DAX Measures** — Built calculated measures for Attendance Rate, Registration vs Attendance trends, and district-level comparisons.
3. **Interactivity** — Added month and district-level filters so stakeholders can drill into performance for any period or region.
